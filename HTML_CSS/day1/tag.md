# HTML 태그 정리

HTML은 웹페이지의 구조와 내용을 작성할 때 사용하는 마크업 언어입니다.  
각 태그는 웹페이지에서 서로 다른 역할을 합니다.

## `<html>`
HTML 문서 전체를 감싸는 가장 바깥쪽 태그입니다.

```html
<html>
    ...
</html>
```

## `<head>`
웹페이지 화면에 직접 표시되지 않는 문서 정보를 작성합니다.  
문서 제목, 문자 인코딩, 외부 파일 연결 등의 내용을 넣을 수 있습니다.

```html
<head>
    <title>웹페이지 제목</title>
</head>
```

## `<body>`
브라우저 화면에 실제로 표시되는 내용을 작성합니다.

```html
<body>
    <p>화면에 보이는 내용입니다.</p>
</body>
```

## `<h1>` ~ `<h6>`
제목을 나타낼 때 사용하는 태그입니다.  
`<h1>`이 가장 큰 제목이고 `<h6>`이 가장 작은 제목입니다.

```html
<h1>큰 제목</h1>
<h2>작은 제목</h2>
```

## `<p>`
문단을 작성할 때 사용하는 태그입니다.

```html
<p>하나의 문단입니다.</p>
```

## `<hr>`
문단이나 내용 사이에 수평선을 표시할 때 사용합니다.

```html
<hr>
```

## `<ul>`
순서가 없는 목록을 작성할 때 사용합니다.

```html
<ul>
    <li>사과</li>
    <li>바나나</li>
</ul>
```

## `<ol>`
순서가 있는 목록을 작성할 때 사용합니다.

```html
<ol>
    <li>첫 번째</li>
    <li>두 번째</li>
</ol>
```

## `<li>`
`<ul>` 또는 `<ol>` 안에서 하나의 목록 항목을 나타냅니다.

```html
<li>목록 항목</li>
```

## `<img>`
웹페이지에 이미지를 표시할 때 사용합니다.  
`src` 속성에는 이미지 경로를, `alt` 속성에는 이미지 설명을 작성합니다.

```html
<img src="profile.jpg" alt="프로필 이미지">
```

## `<a>`
다른 웹페이지나 주소로 이동하는 링크를 만들 때 사용합니다.

```html
<a href="https://github.com/">GitHub</a>
```

## `<table>`
표를 만들 때 사용하는 태그입니다.

```html
<table>
    ...
</table>
```

## `<thead>`
표에서 제목이 들어가는 머리 부분을 구분할 때 사용합니다.

## `<tbody>`
표의 실제 데이터가 들어가는 본문 부분을 구분할 때 사용합니다.

## `<tr>`
표에서 하나의 행을 나타냅니다.

## `<th>`
표의 제목 셀을 나타냅니다.

## `<td>`
표의 일반 데이터 셀을 나타냅니다.

```html
<table>
    <thead>
        <tr>
            <th>이름</th>
            <th>직무</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>김정현</td>
            <td>해외영업</td>
        </tr>
    </tbody>
</table>
```

## `<form>`
사용자가 값을 입력하고 제출할 수 있는 입력 영역을 만들 때 사용합니다.

```html
<form>
    ...
</form>
```

## `<input>`
사용자가 문자, 이메일 등 다양한 데이터를 입력할 수 있는 입력창을 만듭니다.

```html
<input type="text" placeholder="이름을 입력하세요">
```

## `<button>`
사용자가 클릭할 수 있는 버튼을 만듭니다.

```html
<button type="submit">보내기</button>
```

---

## 정리

이번 학습을 통해 HTML 태그마다 역할이 다르다는 것을 배웠습니다.  
제목, 문단, 목록, 이미지, 링크, 표, 입력 폼 등을 각각 알맞은 태그로 구성하면
웹페이지의 기본 구조를 만들 수 있습니다.
